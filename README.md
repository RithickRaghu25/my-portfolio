2. In `index.html`, replace the generic GitHub and LinkedIn URLs with your own profile links.

## Preview locally
Extract this ZIP and open `index.html` in a browser. You can also open the folder in Visual Studio Code and use the Live Server extension.

## Deploy to Vercel (static HTML)
1. Create a GitHub repository, for example `rithick-r-portfolio`.
2. Push `index.html`, `style.css`, `script.js`, and this README to the repository.
3. Go to https://vercel.com and sign in.
4. Choose **Add New → Project**, then import your GitHub repository.
5. For a plain HTML/CSS/JS site, leave the framework preset as **Other** if prompted. No build command is needed; use the project root as the output/static directory if asked.
6. Deploy. Vercel will provide a live `.vercel.app` URL.
7. Test the site on mobile and desktop.

## Push from a terminal
Replace `YOUR-USERNAME` with your GitHub username:

```bash
git init
git add .
git commit -m "Build Rithick R portfolio"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/rithick-r-portfolio.git
git push -u origin main
```
